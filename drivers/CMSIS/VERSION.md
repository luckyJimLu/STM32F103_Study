# CMSIS source provenance

- STM32CubeF1 package: `v1.8.7`
- STM32F1 CMSIS device commit: `c8e9a4a4f16b6d2cb2a2083cbe5161025280fb22`
- CMSIS Core version bundled by STM32CubeF1: 5.4.0

Only CMSIS Core headers, STM32F1 device headers, system templates and the GCC
startup files required by this repository are vendored. The project's compact
HAL implementation remains independent from STM32Cube HAL.
