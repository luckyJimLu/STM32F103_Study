## CMSIS-DSP

教程通过基础数学运算和 FFT 验证 DSP 库。STM32F103 的 Cortex-M3 没有硬件 FPU，因此浮点算法成本较高。

使用要点：

- 选择与 Cortex-M3 匹配的库和编译选项。
- 确认数据类型、缩放和饱和行为，定点 Q15/Q31 与浮点接口不能混用。
- FFT 输入长度必须满足所用实例要求。
- 评估算法时同时观察执行时间、RAM/Flash 占用和数值误差。

## 手写识别与 T9 输入

这两章属于触摸、显示、字库、内存和算法库的组合应用。摘要重点不是识别算法内部细节，而是模块接口：

- 触摸层输出经过校准的坐标/按下/抬起事件。
- UI 层收集笔画或按键序列。
- 识别/检索层返回候选结果。
- 字库层从 NOR Flash 等介质读取字形。
- 显示层负责候选列表、翻页和确认。

移植第三方识别库前应确认授权、数据格式、内存需求和字符集范围。

## 串口 IAP

IAP 允许 Bootloader 接收新固件并写入应用区，然后跳转执行。可靠流程应包含：

1. 规划 Bootloader、应用程序、升级缓存和参数区的 Flash 布局。
2. 链接应用程序到新的起始地址，并设置正确向量表偏移。
3. 升级前校验包头、目标型号、长度、版本和完整性。
4. 按页擦除、按允许粒度写入，并逐段验证。
5. 跳转前关闭中断和外设、清理 SysTick，设置 MSP，再跳到应用复位向量。
6. 上电时保留回滚或重新进入 Bootloader 的路径。

教程示例适合学习基本机制，产品固件还应增加签名验证、防降级、掉电恢复和双镜像策略。

## USB Mass Storage

USB 读卡器实验把 SD 卡或 SPI Flash 通过 USB MSC 暴露给 PC。板级连接使用 PA11/PA12，经 P3 跳线接 D-/D+；它与 CAN 冲突。

核心接口是块设备的容量查询、读块、写块和就绪状态。必须避免 MCU 文件系统与 PC 同时写同一介质，否则容易破坏文件系统。

## USB CDC/VCP

USB 虚拟串口使用 CDC 类在 PC 上呈现串口式接口。它并不是硬件 USART：

- 波特率通常只是主机侧控制信息，不直接决定 USB 传输速率。
- 发送前检查端点状态，不能无限覆盖正在发送的缓冲区。
- 接收回调应快速搬运数据，再交给主循环或任务解析。
- 同样需要 P3 跳线连接 PA11/PA12，且不能与 CAN 同时使用。

## uC/OS-II

### 任务和调度

- 每个任务需要入口函数、独立栈和唯一优先级。
- 高优先级任务持续运行会饿死低优先级任务，任务应阻塞等待事件或适当延时。
- 栈大小需要通过运行测量或水位检查验证。

### 信号量和邮箱

- 信号量用于事件通知或资源计数；二值信号量不自动等同于具有所有权的互斥锁。
- 邮箱一次传递一个消息指针，发送方必须保证消息对象生命周期。
- 中断中只使用内核明确允许的 ISR API。

### 消息队列、事件标志和软件定时器

- 消息队列适合缓冲多个消息，但仍需管理消息内存和满队列策略。
- 事件标志组适合组合等待多个布尔条件。
- 软件定时器回调应短小，复杂工作转交任务处理。

## 综合实验的阅读方法

第 60 章把多个模块集成为菜单式系统，包括电子图书、数码相框、时钟、设置、记事本、手写画笔、照相机、USB、网络/无线、计算器和板级测试。

阅读时建议按依赖拆分：

```text
硬件驱动
  LCD / 触摸 / SD / Flash / USB / 摄像头 / 无线
基础服务
  内存 / FATFS / 字库 / 图片解码 / RTC
界面与输入
  窗口 / 菜单 / 触摸事件 / 文本输入
应用
  相框 / 电子书 / 相机 / 记事本 / 设置
```

不要把综合例程视为单个不可拆分的工程。先对每层建立清晰接口，使用独立测试验证，再逐步组合，更容易定位问题。
