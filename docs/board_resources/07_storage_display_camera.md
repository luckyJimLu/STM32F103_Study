## 内存管理

配套内存管理模块在固定内存池上实现分配、释放和使用率统计。它适合学习动态内存的基本机制，但不等同于标准库 `malloc` 或 RTOS heap。

使用建议：

- 明确各内存池的起止地址、对齐和容量。
- 每次分配检查返回值，所有权经过的每条路径都必须最终释放。
- 中断中避免动态分配。
- 长期运行应用应关注碎片、越界和重复释放。

## SD 卡与 SDIO

教程介绍 SD 卡物理结构、命令/响应、工作模式、SDIO 时钟、寄存器和初始化过程。

实践要点：

1. 上电先低速完成识别和初始化，再切换到较高传输时钟。
2. 正确处理卡类型、容量寻址、总线宽度和状态等待。
3. 块读写接口应明确扇区大小、超时、对齐和 DMA 完成条件。
4. 热插拔场景需要卡检测、卸载和错误恢复。

## FATFS 移植

FATFS 与具体硬件解耦，关键是把 `diskio` 层映射到 SD 卡或其他块设备。

典型流程：

```text
初始化块设备
挂载文件系统
打开/创建文件
读写或遍历目录
同步缓存并关闭文件
卸载文件系统
```

注意事项：

- 每个 API 都要检查 `FRESULT`。
- 断电前调用同步/关闭，否则目录项和数据可能不同步。
- 文件名编码、长文件名、扇区缓存和内存配置会影响 RAM 占用。
- 不要在中断中直接执行文件系统操作。

## 汉字与字符编码

教程讲解字符编码、汉字字库和显示流程，并使用 NOR Flash 保存字库。

- 先明确源码、文件系统和字库使用的编码。
- 根据区位或 Unicode 映射找到字模位置。
- 从字库读取点阵后按字体尺寸和扫描方向绘制。
- 更换字库时同步更新索引、字符范围和字节序。

## 图片显示

- BMP：结构简单，适合直接解析；注意行对齐、像素顺序、位深和上下方向。
- JPEG：压缩率高，需要解码器和工作缓冲区。
- GIF：可能包含调色板、透明和多帧动画，解码状态更复杂。

建议把文件读取、格式识别、解码和 LCD 绘制拆成独立层，并按显示缓冲能力分块解码，避免一次性占用大量 SRAM。

## 照相机实验

照相机实验把 OV7725、FIFO、LCD、SD 卡、FATFS 和 BMP 编码组合起来：

1. 初始化显示、文件系统、摄像头和 FIFO。
2. 采集一帧并刷新到 LCD。
3. 按键触发时生成唯一文件名。
4. 读取像素并按 BMP 格式写入 SD 卡。
5. 同步并关闭文件，处理卡不存在或空间不足等错误。

这是典型的跨模块实验。遇到问题时应先分别验证摄像头预览、SD 块读写、FATFS 文件写入和 BMP 编码，再进行组合。
