## DMA

DMA 在存储器与外设之间搬运数据，可降低 CPU 逐字节处理负担。配置时需明确：

- 正确的 DMA 控制器和通道映射。
- 传输方向、外设/存储器地址递增方式。
- 外设与内存数据宽度。
- 普通或循环模式。
- 优先级和完成/半完成/错误中断。

HAL 外设句柄与 DMA 句柄需要正确关联。缓冲区在 DMA 完成前必须保持有效，不能使用已退出函数的局部数组，也不能在传输中随意改写。

## ADC 单通道采样

教程使用 PA1/ADC1_CH1 采集板载电位器约 0-3.3 V 的电压。基本流程：

1. 配置 ADC 时钟、GPIO 模拟输入和 ADC 参数。
2. 配置规则通道序号与采样时间。
3. 完成 ADC 校准。
4. 启动转换，等待完成并读取结果。
5. 按参考电压换算实际电压。

采样时间不能只追求最短。高阻信号源需要更长的采样时间，否则采样电容可能无法充分充电。

## ADC + DMA

- 单通道连续采集适合稳定刷新一个传感器值。
- 多通道扫描实验使用 ADC1_CH1-CH6，即 PA0-PA5，并由 DMA1_Channel1 搬运。
- 缓冲区顺序与规则序列 rank 一致；修改通道顺序时必须同步修改应用层索引。
- 循环 DMA 下可使用半传输和全传输回调分块处理，避免停止采样。

## 过采样

教程通过单通道过采样获得更高的有效分辨率。核心是多次采样、累加和适当右移/平均；它依赖信号中存在足够噪声或抖动，不能凭空改善 ADC 的绝对精度。

过采样前仍需处理参考电压误差、模拟地、源阻抗、采样时间、布局和校准。

## 内部温度传感器

- 连接到 ADC1_CH16，不占外部 GPIO。
- 需启用内部温度/参考通道，并使用足够长的采样时间。
- 计算结果适合估算芯片结温变化，不应直接当作高精度环境温度。
- 公式中的典型电压和斜率存在器件差异，需要精度时应单点或多点校准。

## 光敏传感器

板载光敏输出连接 PF8/ADC3_CH6。应用层通常对 ADC 原始值做滤波、归一化或阈值判断；阈值应根据实际光照和板卡个体校准。

## DAC

教程使用 PA4/DAC1_CH1：

- 直流输出：设置目标码值并启动通道，可用 ADC 回读或万用表验证。
- 内部三角波：配置波形发生器、幅度和触发源。
- DMA 正弦波：定时器按固定采样率触发 DAC，DMA 循环输出查表数据。

正弦波频率关系：

```text
输出频率 = DAC 触发频率 / 查表点数
```

DMA 波形实验还需要同时核对定时器触发、DMA 通道、DAC 对齐格式、缓冲区类型和循环模式。PA4 输出驱动能力有限，带负载时应考虑运放缓冲。
