## 推荐学习顺序

初学者建议按以下顺序推进：

1. 完成基础、工具链、启动和时钟部分，能够独立建立、编译、下载和调试工程。
2. 依次完成 GPIO、按键、EXTI、串口和定时器，建立对时钟、IO 复用和中断的整体认识。
3. 学习 DMA、ADC、DAC，以及 I2C、SPI、CAN 等通信外设。
4. 最后进入文件系统、USB、IAP、DSP 和 RTOS 等组合型主题。

有经验的开发者可以先查阅[开发板资源速查](01_board_quick_reference.md)，再按问题直接进入对应模块。

## 原书组织方式

- 基础篇：第 1-12 章，讲工具链、寄存器、HAL、启动、CubeMX、时钟和公共组件。
- 入门篇：第 13-44 章，以单个片上外设或板载模块为中心完成闭环实验。
- 提高篇：第 45-60 章，组合存储、图形、USB、升级、DSP 和 RTOS 等中高级能力。
- 大多数实验均按“外设原理 -> 硬件设计 -> 程序设计 -> 下载验证”的结构展开。

## 使用提醒

- 教程的软件版本、网站路径和部分工具界面属于 V1.3 发布时的状态，当前开发环境可能已有变化。
- 本项目采用何种构建系统并不影响外设原理，但 MDK 工程选项、启动文件和链接设置不能直接照搬到 CMake/GCC。
- 正点原子示例中的 `SYSTEM`、`USMART`、内存管理和驱动封装属于配套工程约定，并非 STM32 HAL 的标准组成部分。
- 引脚和跳线结论来自本教程各实验的“硬件资源”与原理图说明；更换开发板版本前应再次核对实物丝印和原理图。
