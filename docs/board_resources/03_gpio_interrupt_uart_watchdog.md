## GPIO 配置思路

1. 使能对应 GPIO 端口时钟。
2. 设置引脚编号、输入/输出/复用模式、上下拉和速度。
3. 对输出引脚先给出安全的初始电平，再启动会驱动外部器件的功能。
4. 使用 `HAL_GPIO_WritePin()`、`HAL_GPIO_TogglePin()` 和 `HAL_GPIO_ReadPin()` 操作 IO。

精英板 LED 由 MCU 下拉灌电流点亮，因此 LED0/LED1 为低电平有效。蜂鸣器的有效电平应以原理图和驱动宏为准。

## 按键输入

- KEY0、KEY1：低电平有效，GPIO 配置为内部上拉。
- WK_UP：高电平有效，GPIO 配置为内部下拉。
- 软件扫描需要消抖，并区分“单次触发”和“按住连续触发”。
- 多键同时按下时，配套扫描函数定义了自己的优先级；应用层不应依赖未明确记录的优先级。

## EXTI 与 NVIC

配置外部中断需同时处理 GPIO、EXTI 映射和 NVIC：

1. KEY0/KEY1 使用下降沿触发，WK_UP 使用上升沿触发。
2. 通过 `HAL_GPIO_Init()` 设置 `GPIO_MODE_IT_FALLING` 或 `GPIO_MODE_IT_RISING`。
3. 使用 `HAL_NVIC_SetPriority()` 设置抢占/响应优先级。
4. 使用 `HAL_NVIC_EnableIRQ()` 开启对应 IRQ。
5. 在 IRQHandler 中调用 HAL 处理函数，并在 `HAL_GPIO_EXTI_Callback()` 中执行简短业务逻辑。

中断回调中不宜执行长延时、阻塞串口或复杂显示刷新。按键消抖可使用时间戳、定时器或任务事件完成。

## USART1 与 CH340

- USART1 TX/RX 使用 PA9/PA10，并通过跳线连接板载 CH340。
- 配置项包括波特率、字长、停止位、校验、收发方向和过采样。
- 常用 HAL 接口包括 `HAL_UART_Transmit()`、`HAL_UART_Receive()`、中断/DMA 版本以及接收完成回调。
- `printf` 重定向只解决格式化输出，不等于建立可靠的异步日志系统。

串口常见故障排查：

1. 检查跳线、端口号、共地和 PA9/PA10 是否接反。
2. 检查系统时钟及 APB2 时钟，错误时钟会导致波特率偏差。
3. 检查 GPIO 复用模式和 USART1 时钟。
4. 中断接收时检查 IRQ、优先级、接收重装和缓冲区生命周期。

## IWDG

独立看门狗由独立低速时钟驱动，适合在主时钟异常时仍提供复位保护。实验用 WK_UP 触发喂狗，以 LED0 观察是否复位。

基本流程：

1. 设置预分频和重装值，估算允许的最长喂狗间隔。
2. 调用 `HAL_IWDG_Init()` 启动；多数情况下启动后不能由软件关闭。
3. 在确认系统关键任务健康后调用 `HAL_IWDG_Refresh()`，不要在无条件定时中断中盲目喂狗。

LSI 频率离散较大，超时时间应留有裕量；需要精确值时可测量或校准。

## WWDG

窗口看门狗要求在指定计数窗口内刷新：太早或太晚都可能导致复位。它由 APB 时钟派生，时钟树变化会影响窗口时间。

使用要点：

- 配置计数器、窗口值、预分频和提前唤醒中断。
- 只在系统状态合法且进入允许窗口后刷新。
- 提前唤醒中断可用于记录故障信息，但不能代替根因处理。

## IWDG 与 WWDG 选择

| 比较 | IWDG | WWDG |
| --- | --- | --- |
| 时钟 | 独立 LSI | APB 派生时钟 |
| 目标 | 对主系统时钟异常也保持保护 | 监控任务执行周期是否过早/过晚 |
| 刷新限制 | 超时前刷新 | 必须在窗口内刷新 |
| 常见用途 | 产品级最终兜底复位 | 周期性软件执行监控 |
