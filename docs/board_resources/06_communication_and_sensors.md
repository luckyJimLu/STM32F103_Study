## 软件 I2C 与 AT24C02

教程使用 PB6 作为 SCL、PB7 作为 SDA，通过 GPIO 模拟 I2C。SDA 采用开漏方式并需要上拉。

实现时必须正确处理：

- START、STOP、ACK/NACK 和字节时序。
- SDA 输入/输出切换或开漏释放。
- 24C02 页写边界、写周期等待和设备地址。
- 总线卡死时的恢复，例如手动产生若干 SCL 脉冲后发送 STOP。

## SPI2 与 NOR Flash

- SCK PB13、MISO PB14、MOSI PB15。
- 片选由独立 GPIO 控制；具体引脚以板卡驱动宏和原理图为准。
- 初始化后先读 JEDEC/器件 ID，确认总线模式和连线。
- 写入前必须写使能，擦除/编程后轮询忙状态。
- 页编程通常不能跨越页边界，擦除粒度通常大于写入粒度。

教程兼容 NM25Q128/W25Qxx 类器件，不同容量可能涉及 3 字节或 4 字节地址模式。

## RS485

- USART2 TX/RX：PA2/PA3。
- PD7 控制收发方向：0 接收，1 发送。
- P5 跳线将 MCU 串口与板载收发器连通。
- 半双工测试至少需要另一块板或 USB-RS485 适配器。

发送完成后必须等待最后一个停止位真正移出，再切回接收模式。A/B 线不可接反，长距离还需关注终端、偏置、屏蔽、接地与波特率。

## CAN

板上通过 TJA1050/SIT1050T 类收发器连接 CAN 总线，并带 120 ohm 终端电阻。

- PA11/PA12 通过 P6 跳线连接 CRX/CTX。
- CAN 与 USB 共用 PA11/PA12，必须二选一。
- 总线两端保留终端电阻，中间节点不应重复增加终端。
- CAN_H/CAN_L 不可接反。
- 配置需匹配波特率、采样点、SJW、过滤器和工作模式。

环回模式只验证控制器软件路径，不能替代两节点实总线测试。

## 触摸屏

- 电阻式触摸需要测量坐标、去抖、滤波和校准。
- 电容式触摸通常由专用控制器报告坐标和触点状态。
- 显示旋转、分辨率或屏幕型号变化后，需要重新检查坐标映射。
- 驱动应把“原始采样 -> 校准 -> 屏幕坐标 -> 事件”分层处理。

## 红外遥控

红外接收头连接 PB9/TIM4_CH4。教程用输入捕获测量脉宽，再按协议解码。

实现重点：

- 识别引导码、位时序、地址/命令及反码校验。
- 处理重复码、超时和噪声脉冲。
- 输入捕获中断只记录时间，完整解码可放到主循环或任务中。

## DS18B20 与 DHT11

两者共用 PG11 接口，但协议不同：

| 器件 | 数据 | 特点 |
| --- | --- | --- |
| DS18B20 | 数字温度 | 1-Wire，总线复位/存在脉冲、温度转换、暂存器与 CRC |
| DHT11 | 温湿度 | 专用单线时序，主机起始信号后读取固定格式脉宽 |

微秒级时序对中断延迟敏感。建议使用定时器或经过校准的短延时，并设置超时，避免传感器缺失时死循环。

## NRF24L01

- 与 NOR Flash 共用 SPI2。
- CE PG8、CSN PG7、IRQ PG6。
- 典型初始化包括地址、信道、数据速率、自动应答、重发参数和有效载荷长度。
- 双向实验需要两个节点；排查时先读回寄存器，确认 SPI 通信正常。

同一 SPI 总线上的所有设备必须拥有独立片选；访问 NRF24L01 时保持 NOR Flash 片选为高。

## 内部 Flash 模拟 EEPROM

内部 Flash 不能像 EEPROM 一样按字节任意覆盖：写入通常只能把位从 1 改为 0，恢复为 1 需要擦除页。

产品化时应考虑：

- 页擦除寿命和磨损均衡。
- 断电保护、记录版本、长度和 CRC。
- 双页切换或日志式写入，避免更新中途丢失全部配置。
- 擦写期间的中断执行位置和 Flash 忙状态。

## OV7725 摄像头

OV7725 通过 SCCB 配置寄存器，经并行 D0-D7 输出像素；板载 FIFO 缓冲一帧数据。

- 数据 PC0-PC7，VSYNC PA8/EXTI8。
- SCCB：SCL PD3、SDA PG13。
- FIFO 控制：OE PG15、WRST PD6、WEN PB3、RCLK PB4、RRST PG14。
- 初始化顺序包括 IO/SCCB、读取器件 ID、传感器寄存器序列、FIFO 写入和帧读取。

安装模块时应断电并确认方向。帧同步、FIFO 复位和读写时序错误会表现为花屏、错位或帧撕裂。
