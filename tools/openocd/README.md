# OpenOCD (片上调试与烧录工具)

## 说明
用于存放 OpenOCD (Open On-Chip Debugger) 可执行文件及官方 target/interface 脚本。

## 推荐下载
- **Windows 构建版**：[xPack OpenOCD](https://github.com/xpack-dev-tools/openocd-xpack/releases) 或 [sysprogs openocd](https://sysprogs.com/w/tools/openocd/)
- **目录组织**：
```
tools/openocd/
├── bin/
│   └── openocd.exe
├── scripts/
│   ├── interface/
│   └── target/
└── ...
```
